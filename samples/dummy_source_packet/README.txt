================================================================================
SPACEFILL FORM STUDIO — SAMPLE DUMMY DATA PACKET
================================================================================
This folder contains 6 categorized source files pre-calibrated to auto-fill
the 38-page USCIS I-129 (and standard government/tax) PDF forms.

CATEGORIES INCLUDED:
1. 01_company_and_petitioner.txt        -> Petitioner company, FEIN tax ID, financials, signatory.
2. 02_personal_and_identification.txt   -> Beneficiary full name, DOB, SSN, A-Number, passport, address.
3. 03_education_and_degrees.txt         -> Graduate & undergraduate degrees, university, certifications.
4. 04_job_offer_and_compensation.txt    -> Job title, SOC code, salary ($185k), worksites, duties.
5. 05_tax_and_immigration_history.txt   -> I-94, current H-1B status, prior receipt numbers.
6. 06_structured_records.csv            -> Tabular dataset for fast multi-field matching.

HOW TO USE IN STUDIO:
1. Upload your 38-page form (e.g. samples/i129_sample_form.pdf).
2. In the right-hand Source Panel, click "Select Folder" and choose this "dummy_source_packet" folder.
3. Click "⚡ Fill Form" — SpaceFill will extract all data and populate the fields instantly!
